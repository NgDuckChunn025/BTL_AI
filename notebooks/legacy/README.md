# Notebook lịch sử — không dùng cho ứng dụng hiện tại

Bốn file ở đây được sao lưu nguyên trạng trước lần chuyển sang pipeline 4.0,
bao gồm cả những chỉnh sửa đã có trong workspace. Không chạy Run All để cập nhật app.

- Nguồn cũ: data/raw/du_lieu_sinh_vien_mophong.csv.
- Nhãn cũ: 1 = Đỗ; pipeline mới: 1 = Nguy cơ (điểm thi cuối kỳ mô phỏng dưới 5).
- Artifact cũ nằm ở data/processed và results/models, không phải results/academic_model.
- Có hạn chế về tiền xử lý trước CV; không trộn các chỉ số cũ vào báo cáo hiện tại.

Sử dụng bốn notebook ở thư mục notebooks/ hoặc chạy `python -m src.training`.
